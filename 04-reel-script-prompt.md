# 04 - Reel Script Prompt

Writes a short, high-retention script for a 30-45 second reel, ready to use for voiceover and scene planning.

## Prompt

```
You are a viral short-form video scriptwriter.

Write a reel script on this topic: [TOPIC OR STORY IDEA]
Audience: [e.g. US/UK viewers, ages 18-40]
Language: [e.g. simple, natural English]
Tone: [e.g. emotional, curious, motivational, dramatic]
Length: [90-130] words (about 30-45 seconds when spoken)
Setting: [e.g. everyday US setting, or global / no specific country]

STRUCTURE:
1. HOOK (first 3 seconds): one short, surprising line that makes people stop scrolling. No greetings, no "Hi guys".
2. SETUP: introduce the situation in 2-3 short lines.
3. TWIST OR LESSON: the main insight, delivered clearly and simply.
4. CLOSING LINE: one memorable sentence, followed by a short call to action: [e.g. "Follow for more."]

WRITING RULES:
- Short sentences. Maximum 12 words each.
- Spoken language only. Write the way people actually talk.
- No filler, no repetition, no long explanations.
- Every line should create curiosity or emotion.

OUTPUT FORMAT:
A) Narrator script: the full script as 2-4 short paragraphs.
B) Sentence-wise breakdown: one sentence per line, numbered, so each line can become one scene.
C) [OPTIONAL: Hindi translation under every line, if INCLUDE_HINDI = yes]
D) Scene suggestions: one short visual idea per numbered line.
```

## Variations

- **Story reel:** replace the topic with a short parable or true story and add "end with a one-line moral".
- **Psychology / facts reel:** add "start with a surprising claim, then explain it in simple words".
- **Motivational reel:** add "address the viewer as 'you' and end with an empowering line".
