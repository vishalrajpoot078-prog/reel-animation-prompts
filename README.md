# reel-animation-prompts

Free, open-source master prompts and templates for creating 9:16 animated reels and short videos with AI.

Instead of rewriting prompts from scratch for every video, copy a template, fill in the `[BRACKETS]`, and paste it into your AI tool of choice (Claude, ChatGPT, Gemini, or an image generator).

## What's inside

| File | What it does |
|---|---|
| `01-html-reel-master-prompt.md` | Generates a complete one-file 9:16 HTML animation (scenes, captions, transitions, replay button) |
| `02-ai-image-scene-prompt.md` | Keeps AI-generated scene images consistent in style and character across a whole reel |
| `03-camera-drift-prompt.md` | Plans slow zoom and drift motion for each still image, ready for any video editor |
| `04-reel-script-prompt.md` | Writes a short, high-retention reel script with a hook, scene markers and a closing line |

## How to use

1. Pick the template that matches your step (script, images, motion, or full HTML animation).
2. Copy the prompt block and replace every `[BRACKET]` with your own details.
3. Paste it into your AI tool and review the output.
4. Reuse the same style settings across reels so your channel looks consistent.

## Suggested workflow

Script (`04`) -> Scene images (`02`) -> Camera motion (`03`) -> Edit and export.
Or use `01` to generate a fully animated HTML reel directly from your script.
